## Global Style

- Final required output format: vertical 3:4 slides, for example `1080x1440`, `1200x1600`, or equivalent. Older reference folders may be visually useful, but do not copy their aspect ratio if they are not 3:4.
- Warm cream/marfil background with soft editorial lighting.
- Near-black/dark brown bold uppercase typography.
- Terracotta/copper emphasis for key words, icons, dividers and CTA elements.
- Small rounded slide counter in top left: `01/08`, `02/08`, etc.
- Thin terracotta line extending from the counter.
- `@jaime_cabadas` top right, small and clean.
- Realistic Jaime portrait integrated into the generated scene.
- Practical workspace props: laptop, notebook, coffee, papers, sticky notes, whiteboard, UI mockups, checklists, folders, phone, microphone/camera when useful.
- Visuals feel like a premium operational desk, not a generic template.
- Future outputs must improve on the references by adding more variety: avoid repeating the same Jaime pose, desk angle or object set across the whole carousel.
- Backgrounds and props must be specific to the topic. Use inbox screens for email, workflow nodes for automation, content boards for content, dashboards for metrics, and real tool logos/name cards when specific tools are mentioned.

## Slide Pattern

### Slide 1

Role: hook.

Pattern:

- Huge headline, 3-5 lines.
- Terracotta highlight on the main concept (`IA`, `AUTOMATIZAR`, etc.).
- Jaime visible and integrated naturally.
- Supporting workspace context on desk or wall.
- Short subtext, not a paragraph.

Use for future:

- Make the topic instantly obvious.
- Include Jaime when the topic is strategic or personal-brand authority.

### Slide 2

Role: mindset shift / first principle.

Pattern:

- Strong line like `PRIMERO:` or equivalent.
- Explains what not to do first.
- Uses comparison, small framework, process table or before/after structure.
- Less portrait dependency; more systems/diagram visual.

Use for future:

- Introduce the core idea that prevents the common mistake.

### Slide 3

Role: first main category or framework section.

Pattern:

- Big category heading.
- Numbered list of 4-5 concrete items.
- Visual support through laptop/tablet UI, strategic map, notes or diagram.
- Paper/desk elements reinforce the list.

Use for future:

- Start the practical breakdown.

### Slide 4

Role: second category.

Pattern:

- Big heading with terracotta keyword.
- Jaime may appear using camera/mic/laptop if the category relates to content/communication.
- 4-5 bullets with icons.
- A small insight box can appear near the bottom.

Use for future:

- Make it feel actionable, not theoretical.

### Slide 5

Role: third category.

Pattern:

- Strong heading.
- Desk scene often shifts from laptop to phone/proposal/paper.
- Left-side list with small icons.
- Bottom microcopy reinforces the principle.

Use for future:

- Vary visual props so every slide is not just laptop.

### Slide 6

Role: operations/system category.

Pattern:

- Process/SOP/whiteboard look.
- Checklist, folders, repeated cards, or board structure.
- Heading on left, system map or operational board on right.

Use for future:

- Use for workflows, SOPs, documentation, internal systems.

### Slide 7

Role: automation/category map.

Pattern:

- More complex but still readable process diagram.
- Icons and arrows connect steps.
- Key reminder box at bottom.
- Strongly tied to IA as a system, not magic.

Use for future:

- Use when explaining flows, automations, agents, pipelines.

### Slide 8

Role: action / CTA.

Pattern:

- Jaime portrait returns.
- Big action headline: choose, delegate, comment, save, start.
- 3-4 clear next steps.
- CTA button/card near bottom.
- Save/comment prompt.

Use for future:

- Always connect to the lead magnet redemption keyword.
- Keep the CTA visually native to the slide, not appended after generation.

## Generation Rule

Generate every final slide with Image 2 as a full finished composition. The prompt for each slide must include:

- vertical 3:4 format requirement;
- exact slide text;
- slide number;
- `@jaime_cabadas`;
- whether Jaime appears;
- if Jaime appears, a distinct pose/composition/crop for that slide;
- scene description;
- UI/desk/paper/checklist props;
- topic-specific background and objects;
- real tool logos or real tool-name cards when relevant;
- typography hierarchy;
- palette;
- CTA if relevant.

Do not use the reference slides as simple background inspiration. Use them as examples of finished outputs.
